## 💻 Essential Git Commands

| Command | Description |
|---|---|
| `git --version` | Check Git version |
| `git init` | Initialize a repository |
| `git status` | Check working tree status |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Commit changes |
| `git log` | View commit history |
| `git branch` | List branches |
| `git switch branch-name` | Switch branches |
| `git merge branch-name` | Merge branches |
| `git clone URL` | Clone a repository |
| `git push` | Upload local commits |
| `git pull` | Fetch and integrate remote changes |

## 🔄 Basic Git Workflow

The basic Git workflow involves four stages:

1. **Working Directory:** Create or modify project files.
2. **Staging Area:** Select changes using `git add`.
3. **Local Repository:** Save changes using `git commit`.
4. **Remote Repository:** Upload changes using `git push`.

### Practical Workflow

```bash
# Initialize repository
git init

# Check repository status
git status

# Stage changes
git add .

# Commit changes
git commit -m "Initial commit"

# Connect remote repository
git remote add origin <repository-url>

# Push changes to GitHub
git push -u origin main
```
